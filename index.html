Sistemas privados

Em produção, com código e dados fechados. Descrevo a arquitetura, sem expor informação de clientes.

Syncfy

CRM imobiliário com IA

Privado

Plataforma para imobiliárias que reúne gestão de leads e imóveis, atendimento por WhatsApp e análise de documentos com IA.

API e workers
ASP.NET Core em .NET 10, Entity Framework Core e Dapper sobre SQL Server. Workers independentes para documentos, importação de imóveis, geolocalização por CEP e IA, com filas no Azure Storage. Chat em tempo real com SignalR e Azure Web PubSub.
WhatsApp
Integrações nativas com a WhatsApp Cloud API da Meta, a Twilio e a Z-API. Um webhook dedicado só recebe e enfileira as mensagens, e workers cuidam dos fluxos, dos templates e do envio.
IA
OpenAI e Google Gemini para ler documentos e analisar o risco da locação, com um worker próprio para reprocessar.
Infraestrutura
Contêineres Docker em Kubernetes (AKS), com imagens no Azure Container Registry, ingress NGINX e certificados Let's Encrypt. Ambientes de homologação e produção, com deploy por GitHub Actions.
Observabilidade
Métricas com Prometheus e painéis no Grafana para API, banco, filas, workers e WhatsApp. Logs com Grafana Loki, erros no Sentry e Application Insights nas Functions.
Dados
SQL Server, MongoDB, Redis e RabbitMQ, com Azure Storage (Blob, Queue e Table) e Data Lake.
Documentos e e-mail
iText e DocX para gerar contratos em PDF e Word, e SendGrid para e-mail.
Qualidade
xUnit, NUnit, Moq e FluentAssertions nos testes, e k6 nos testes de carga.
Web
Vue 3 com módulos de documentos, leads, chat e gerenciador de anúncios, em português, inglês e espanhol.
BackOffice
Painel administrativo em ASP.NET Core e Vue 3, com fluxos de WhatsApp, réguas de notificação e prompts.
Mobile
App em Expo e React Native, com build por EAS e Fastlane.
Automação
Azure Functions para tarefas auxiliares e o pacote próprio Syncfy.Triggers: workers de fila e timer por atributos, no estilo Functions, sem depender do runtime.

Aviso. O código, as telas e os dados do Syncfy são privados e ficam fora de repositórios públicos, por isso não há demonstração nem capturas de tela. Esta descrição resume a arquitetura e não substitui o que o produto faz hoje; para ver o produto, visite o site da Syncfy.

Chatterie Vet

Gestão de clínica veterinária

Privado

Sistema para a rotina de uma clínica veterinária, da agenda e do prontuário ao financeiro, com portal para o tutor acompanhar o pet.

Clínica
Agenda, pacientes, prontuários, histórico de saúde, internações com medicação, alimentação e evolução, e controle diário dos veterinários.
Comercial
Orçamentos, vendas, estoque, pagamentos, comissões, notas fiscais e relatórios.
Atendimento
Fluxo de chatbot e sessões de WhatsApp, além de um portal do cliente.
API
ASP.NET Core em .NET 10 e Entity Framework Core sobre SQL Server, com perfis e permissões por módulo.
Web
React 18, TypeScript, Vite, shadcn/ui e TanStack Query, publicado no Azure Static Web Apps.
Mobile
App em Expo e React Native, com login por biometria e notificações push.

Aviso. O Chatterie Vet é um sistema privado, sem demonstração pública. Não mostro capturas de tela porque elas expõem dados de clínica, tutores e pacientes. A descrição resume os módulos que existem no código.
