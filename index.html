API e workers
ASP.NET Core em .NET 10, Entity Framework Core e Dapper sobre SQL Server. Workers independentes para WhatsApp, documentos, importação de imóveis e processamento de IA, com filas no Azure Storage.
Tempo real
SignalR e Azure Web PubSub para o chat.
Web
Vue 3 com módulos de documentos, leads, chat e gerenciador de anúncios, em português, inglês e espanhol.
BackOffice
Painel administrativo em ASP.NET Core e Vue 3, com fluxos de WhatsApp, réguas de notificação e prompts.
Mobile
App em Expo e React Native.
Pacote próprio
Syncfy.Triggers: workers de fila e timer por atributos, no estilo Azure Functions, sem depender do runtime de Functions.

Chatterie Vet

Gestão de clínica veterinária

Sistema para a rotina de uma clínica veterinária, da agenda e do prontuário ao financeiro, com portal para o tutor acompanhar o pet.

Clínica
Agenda, pacientes, prontuários, histórico de saúde, internações com medicação, alimentação e evolução, e controle diário dos veterinários.
Comercial
Orçamentos, vendas, estoque, pagamentos, comissões, notas fiscais e relatórios.
Atendimento
Fluxo de chatbot e sessões de WhatsApp, além de um portal do cliente.
API
ASP.NET Core em .NET 10 e Entity Framework Core sobre SQL Server, com perfis e permissões por módulo.
Web
React 18, TypeScript, Vite, shadcn/ui e TanStack Query, publicado no Azure Static Web Apps.
Mobile
App em Expo e React Native, com login por biometria e notificações push.

Aviso. O Chatterie Vet é um sistema privado, sem demonstração pública. Não mostro capturas de tela porque elas expõem dados de clínica, tutores e pacientes. A descrição resume os módulos que existem no código.
